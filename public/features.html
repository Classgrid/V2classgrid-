Platform Features

Everything in Classgrid

A comprehensive look at every feature available on the platform — from organization management and AI-powered learning to security and real-time collaboration.

01
Organization Setup

Every institution starts as an Organization — a unified workspace for faculty, classrooms, and students under one roof.

  • One-click application: Admins apply with institute name, logo, and contact details
  • Dual secure codes: Each org gets a unique Organization Code (for faculty) and Honor Code (for students) — never shared publicly
  • Org Admin dashboard: Full visibility into faculty, students, classrooms, and settings
  • Faculty management: Add or remove faculty via email invite with auto password setup
  • Single-org enforcement: Users belong to exactly one organization — no cross-org data leaks
  • Organization deletion: Full hard-delete with email verification — removes all data permanently
02
Faculty Dashboard

Faculty get a centralized command center to manage classrooms, content, and students in one place.

  • Profile management: Update name, email, and password from the dashboard
  • Classroom overview: See all classrooms with student counts and join codes at a glance
  • Activity logs: Track events across classrooms — joins, announcements, uploads
  • Notification center: In-app alerts for join requests, system events, and student activity
  • Faculty invite flow: Email invite → set password → enter Org Code → start teaching
  • Admin password reset: Org Admins can trigger password reset emails for any faculty
03
Classroom Controls

Classrooms are the core workspace — structured, secure, and fully controlled by faculty.

  • Create classrooms: Set name, subject, description, and capacity — limited per plan
  • Join via code: Students join instantly using a 6-character classroom code
  • Approval-based join: Faculty can require manual approval before students gain access
  • Bulk approve/reject: Process multiple join requests at once with enforced limits
  • Member management: View all students, remove members, and track join history
  • Archive classrooms: Archive old classrooms to keep the dashboard clean
  • Classroom settings: Toggle join requests, set capacity limits, manage visibility
04
AI Academic Engine

Classgrid AI is embedded directly into the classroom workflow — serving students and faculty with contextual intelligence.

  • Instant doubt solving: Students get AI-generated answers in real time without waiting
  • Smart Assistance: AI assists students with uploaded notes and classroom content
  • Lecture summaries: Condenses long materials into structured, digestible summaries
  • Academic assistance: Contextual help aligned with classroom curriculum
  • Content support: Helps faculty organize and manage academic content intelligently

AI Routing: Primary inference via Groq (LLaMA). On rate limits, the system auto-falls back to Gemini Flash — zero interruption.

05
Student Experience

Students get a clean, focused environment designed for learning — not distractions.

  • Personal dashboard: See enrolled classrooms, pending requests, and notifications
  • Flexible entry: Join by code (instant) or via request (approval) — both supported
  • Notes & announcements: View all faculty-posted notes and classroom material in real time
  • Track progress: Monitor attendance and academic progress within the classroom
  • Peer contribution: Upload notes to a dedicated student section — kept distinct
  • Honor Code joining: Enter org Honor Code to link accounts — prevents cross-org issues
06
Notes & Content

Structured content delivery — faculty upload material, students access it instantly, and peer contributions stay separate.

  • Faculty uploads: Upload PDFs, documents, and study material to specific classrooms
  • Student uploads: Students contribute notes to a dedicated peer resources section
  • Review system: Student-uploaded notes go through approval before becoming visible
  • Org-isolated notes: Notes visible only within the same organization — no cross-org access
  • Secure storage: Files stored on Supabase with signed URLs and access controls
  • Announcements: Faculty post class-wide updates visible to all enrolled students
07
Smart Attendance

Attendance tracking built natively into the classroom — no external tools or manual spreadsheets.

  • Faculty-initiated: Start and stop attendance sessions from within the classroom
  • Daily reports: View who was present, absent, or late for each session
  • Weekly reports: Aggregate view showing attendance trends across the week
  • Monthly summaries: Full monthly breakdown for academic record-keeping
  • Student view: Students see their own attendance history and participation record

Pro Plan Only: Smart Attendance, reports, and advanced analytics are exclusive to the Pro plan.

08
Real-Time Chat

Live collaboration for doubts, peer discussion, and academic exchange — mirroring in-person interaction.

  • Live messaging: Students and faculty communicate in real time within each classroom
  • Faculty monitoring: Teachers can observe and moderate all chat activity
  • Scoped context: Chat is scoped to individual classrooms — no cross-classroom noise
  • Active tracking: Faculty see who's online and engaging in the classroom right now
09
Security & Auth

Enterprise-grade security built into every layer — authentication, authorization, and data protection.

  • 4 login providers: Google OAuth, GitHub, LinkedIn, and Email/Password — all verified
  • JWT encryption: Every session is encrypted with JSON Web Tokens — no plain-text auth
  • bcrypt hashing: All passwords are salted and hashed using bcrypt — never stored in plaintext
  • Email verification: New accounts must verify email before gaining full access
  • Login alerts: Automatic email notification sent on every login — full account awareness
  • Role-based access: Strict separation — Super Admin, Org Admin, Faculty, Student scoped
  • Code isolation: Org Codes and Honor Codes prevent unauthorized cross-org access
10
Notifications

Stay informed without noise. Notifications are contextual and actionable — in-app and via email.

  • In-app alerts: Join approvals, classroom updates, and system alerts — all in the dashboard
  • Email alerts: Invites, resets, org approvals, join approvals, and login alerts via SMTP
  • Pro activation email: Admins receive confirmation with plan details and expiry date
  • Org approval email: Admins receive org codes, honor codes, and onboarding details

12
Org Admin Control

Institution-level administration — full control over your organization's faculty, students, classrooms, and settings.

  • Faculty Control: Invite and manage teaching staff within plan limits. Remotely reset passwords and promote faculty to Org Admin roles.
  • Student & Classroom Oversight: Track total student enrollment across all classrooms and instantly evict students from the institution.
  • Notes Moderation: Review, approve, or reject student-uploaded notes before they become visible to the organization.
  • Organization Announcements: Broadcast rich-text announcements directly to the dashboards of all faculty and students.
  • Real-time Analytics: Monitor daily active users, detailed role breakdowns, and platform usage metrics over the last 7 days.
  • Billing & Capacity Management: View current subscription tier and monitor faculty/student limit allocations in real-time.
  • Identity & Security: Update institution branding (logo), manage secure Faculty and Student Join Codes, and review comprehensive audit logs of administrative actions.
